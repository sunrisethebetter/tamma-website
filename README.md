# Tamma website

Official static website for https://tammannn.xyz, hosted with GitHub Pages.

- `/` — Studio homepage
- `/privacy-policy/` — Privacy Policy
- `/terms-of-service/` — Terms of Service
- `/app-ads.txt` — Authorized advertising sellers

Contact: tammaentreprises@gmail.com

## Local preview

Run `python3 -m http.server 8765` from this directory. No build step or external dependency is required.

## Publishing

GitHub Pages deploys `main` from the repository root. Keep `CNAME` set to `tammannn.xyz`.
